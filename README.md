# Hotel Booking Demand Analysis

This project analyzes hotel booking data, including cancellations, guest behavior, prices, and stay duration.

## Project structure

- `notebooks/` — Jupyter Notebook report
- `src/` — reusable cleaning and analysis code
- `data/raw/` — original dataset
- `data/processed/` — cleaned dataset
- `pages/`, `Home.py` — Streamlit web interface
- `main.py/` — FastAPI backend
- `telegram_bot/` — Telegram WebApp/menu

## How to run

```bash
streamlit run Home.py
```
